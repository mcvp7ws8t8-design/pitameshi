# ホール&キッチン

2人がオンラインで、1人はホール、1人はキッチンを担当して、お店を回す一人称視点の3Dゲーム。
ぴためし本体とは別のプロジェクト(別の Worker)。ルートの `npm test` / `typecheck` / `build` には含まれない。

## 遊び方
2人が部屋に入り、ホールとキッチンを1人ずつ選ぶと3秒後に始まる。1回5分。
大量に来るお客さんをどれだけさばけるかを競う。怒って帰った人が15人になるとゲームオーバー。

操作: WASD で歩く / マウスで見回す(画面クリックで開始)/ E で触る / R で調理する注文を切り替え(キッチン)

- メニューは **料理20種**(キッチン)と **ドリンク20種**(ホール)。お客さん1人が料理1つとドリンク1つを注文する。
- お客さんは1〜4人のグループで来る(人数が入る一番小さい空き卓に、全員そろって案内される)。グループの人数ぶん、それぞれが料理1つとドリンク1つを注文する。さばいた数は「人数」で数える
- 席は **2名掛け8卓・4名掛け4卓**(計12卓・椅子32脚)。席は「5A」のように、卓の番号と椅子の記号で呼ぶ
- **ホール**: 席で E で注文を取る → ドリンクバーで E でドリンクを作る(R で作る注文を選ぶ)→ 受け渡し台で E で料理を取る → 席で E でドリンクと料理を出す。トレーは料理とドリンク合わせて4つまで
- **キッチン**: 料理は、食材を2〜3個、**冷蔵庫から取って**、それぞれ「焼く・茹でる・揚げる」のどれかで調理し、**盛り付け台**で1皿にする。食材は40種(焼く16・茹でる12・揚げる12)、料理は20種(どの食材もどれかの料理で使う)
  1. 冷蔵庫で E: 選んでいる注文(なければ一番古い注文)の食材を、手に持てるだけ取る(手には生・調理済みを合わせて4つまで)
  2. 調理場で E: 持っている生の食材のうち、その調理場の調理法に合うものを入れる(選んでいる注文を優先)。調理場は焼く5・茹でる4・揚げる2。できあがりがあれば、E で取る
  3. 盛り付け台(受け渡し窓のキッチン側)で E: 調理済みの食材を置く。1皿ぶんそろうと完成して、受け渡し台に出る
  - 例: ハンバーグ定食 = 合い挽き肉(焼く)+ にんじん(茹でる)+ フライドポテト(揚げる)
- **ドリンクを出すと、お客さんの我慢ゲージが戻る**(戻る量は種類で違う。手間のかかるお酒ほど大きい)。料理が先に届いて食べ始めたあとに出しても効果はない
- お客さんは来店の間隔がだんだん短くなる(6秒 → 1秒)。席が空くまで入口で並び、並びすぎると帰る
- さばききれない量が来るのが前提。記録は「さばいた数」だけ

方針: 設備の強化やお金は入れない。「料理をどれだけさばけるか」だけを競う。
まだないもの: 皿の片付け・洗い物、声のやり取り(外部のツールで話す想定)。
数字は `src/shared/game.ts` の `CONFIG` にまとめてある。まだ調整していない。

## コマンド
```
cd games/hall-kitchen
npm install
npm test            # 動きのルール(src/shared/room.ts)のテスト
npm run typecheck
npm run build && npx wrangler dev   # http://localhost:8787 を2つのタブで開く
npm run deploy      # Cloudflare に公開(Durable Objects を使う)
```

## 構成
- `src/shared/room.ts` 部屋の状態と動きのルール。サーバーとクライアントで共有
- `src/shared/game.ts` お客さん・注文・調理・配膳のルール(時間は tick で進める)
- `src/shared/menu.ts` 食材40種(調理法・調理時間)・料理20種(レシピ)・ドリンク20種(ゲージが戻る量)
- `src/shared/layout.ts` 卓・椅子・調理場・ドリンクバー・受け渡し台の位置と、近くにあるものの判定
- `src/shared/protocol.ts` 通信メッセージ
- `src/server/index.ts` Worker と、1部屋 = 1つの Durable Object(WebSocket)
- `src/client/` Three.js の画面と操作。画像・3Dモデルのファイルは使わず、形と質感はすべてコードで作る
  - `scene.ts` 店(床・壁・窓・家具・キッチン設備・照明・日光の影) / `textures.ts` Canvas で描く質感
  - `people.ts` 人のモデル / `items.ts` 食材40種・料理(皿に食材を盛る)・ドリンク20種のモデル
  - `view.ts` ゲームの状態を3Dに映す / `viewmodel.ts` 一人称の手元(トレー・皿)
  - `main.ts` 通信・操作・画面の部品(HUD)

## 見た目の確認
URL に `?debug` を付けると、ブラウザのコンソールから `__debug.play(役割, x, z, yaw, 状態)` で、サーバーなしで任意のゲーム状態を表示できる(見た目の確認用。通常のプレイには影響しない)。
