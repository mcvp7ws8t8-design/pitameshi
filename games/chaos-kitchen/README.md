# てんやわんやキッチン

ブラウザで遊べる協力料理ゲーム(オーバークック風)。キッチンで料理を作り、ホールで接客し、AIの相棒に日本語で手順を教えて育てる。**全100ステージ**(10ワールド×10)。

- 遊ぶ: `index.html` をブラウザで開く(ビルド不要)。`?unlock=all` を付けると全ステージ選択可。
- 操作:
  - キーボード 1P=WASD/E(つかむ・置く)/Q長押し(切る・洗う)、2P=矢印/`.`/`,`長押し、Esc=ポーズ
  - コントローラー(Switchのプロコン/ジョイコン、Xbox、PS など。ブラウザのGamepad API): スティックか十字キーで移動、下か上ボタン=つかむ・置く、左か右ボタン長押し=切る・洗う、Start=ポーズ
  - メニューもキーボードの矢印/コントローラーの十字キー・スティックで選べる(A=決定、B=もどる)
  - スマホは画面のスティックとボタン
- 人数: 人間 1〜4人(コントローラーの数+キーボード2人まで) + AI 0〜3人、合計4人まで。操作の割り当てはステージ選択画面に出る(コントローラーが先、足りなければWASD→矢印)
- AI: 画面下のチャットに「レタスを取って」「サラダの作り方」「ホールお願い」「おまかせ」のように指示。手順を通しで教えて提供まで成功すると料理を覚える(全ステージ・全AIで共有、ブラウザに保存)。

## 構成
| ファイル | 内容 |
|---|---|
| `js/data.js` | 材料12種・調理器具3種(コンロ/フライヤー/オーブン)・料理31種・イベント。お手本の手順も作る |
| `js/stages.js` | 10ワールド×10ステージの台本と、地形・設備配置の生成(種が同じなら毎回同じ)。構造の検査 `validate` |
| `js/calibration.js` | AI3人の処理能力の実測値(出題の速さの下限に使う)。`tools/calibrate.cjs` が作る |
| `js/game.js` | エンジン・画面(ホーム/ステージ選択/結果/ポーズ)・スマホ操作 |
| `js/art3d.js` | **立体表示**(Three.js)。傾けたカメラ・光と影・ブロック状の設備・立体のキャラ。HUDや吹き出しは2Dを重ねる。WebGLが使えない端末では自動で `art.js` の2D表示に戻る |
| `js/vendor/three.min.js` | Three.js r147(MIT。npmから取得して同梱。ゲーム専用で、ぴためし本体のビルドには入らない) |
| `js/art.js` | 見た目(かわいいポップ): 丸いシェフ・設備・床・料理・エフェクト・HUD。HUD・2D表示(3Dが使えないときの代わり)・エフェクト。画像素材なし |
| `js/sound.js` | 効果音とBGM(WebAudioで合成。音声ファイルなし。BGMはワールドごとに調とテンポが変わる) |
| `js/ai.js` | AIの言葉の理解・経路探索・作業・おまかせ |
| `test/stages.test.js` | 100ステージの構造・一意性・決定性などのテスト |
| `tools/simulate.cjs` | 全ステージをAIが自動プレイして遊べるか確かめる(要 playwright) |
| `tools/calibrate.cjs` | 各ステージでAIが捌ける皿数を測り `js/calibration.js` を更新 |

## ステージの作り
- ワールド: 1 はじめてのキッチン / 2 スープの季節 / 3 ホールデビュー / 4 お肉の日 / 5 ごはん屋さん / 6 バーガーショップ / 7 揚げ物パーティ / 8 こおりの国 / 9 ぶんぎょうキッチン / 10 グランシェフ
- 形: 箱・L字・U字・廊下・島・リング・十字・階段・柱・(分業は2〜3部屋)
- ギミック: 氷の床(滑る)・ベルトコンベア(流される)・材料の在庫制限・分業の厨房(受け渡し台で連携)・焦げやすさ・イベント(停電/滑る床/団体客ラッシュ/火事/ネズミ)
- 制限時間: ワールドの基本時間 × 性格(ダッシュ0.65・長丁場1.6・ラッシュ0.85・ボス1.4)。接客モードは1.35倍
- 星: スコアが目標(★1/★2/★3)に届いた数。前のステージを★1以上でクリアすると次が解放

## 検証
```
node --test games/chaos-kitchen/test/stages.test.js     # 構造の検査
node games/chaos-kitchen/tools/simulate.cjs 1 100        # AIによる自動プレイ(分業ステージはAI単独では届かないので対象外)
node games/chaos-kitchen/tools/calibrate.cjs             # 処理能力の再測定
```
難易度(出題の速さ・星の基準・制限時間)は仮の値。人が遊んでみて調整する前提。
